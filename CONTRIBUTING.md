# Contribuir

Obrigado pelo interesse. Esta skill é open-source sob licença MIT.

## Como propor mudanças

1. Faça um fork e crie um branch a partir de `main`.
2. A fonte de verdade do comportamento é `skills/geo-content-brief/SKILL.md`. Comece por lá.
3. Mantenha o frontmatter (`name`, `description`, `metadata`) intacto.
4. Use Conventional Commits (`feat:`, `fix:`, `docs:`…).
5. Abra um PR descrevendo o que muda e por quê.

## Princípios

- **Voz direta.** Frases curtas, voz ativa, zero floreio. Sem léxico inflado, sem paralelismo negativo. O que vale para o conteúdo que a skill ajuda a estruturar vale para a documentação.
- **Vendor-neutral.** A skill serve a qualquer pessoa, marca ou negócio. Mudanças não devem amarrá-la a um fornecedor, nicho ou plataforma específica.
- **Direcional, não garantia.** Os números vêm de pesquisa pública e ordenam prioridade. Nunca os transforme em promessa de posição ou de citação.
- **Estruturar, não redigir.** A skill entrega o brief e o gate; a redação fina fica para o escritor. Mudanças que tentam fazer a skill escrever a página inteira vão contra o princípio central.

Dúvida ou ideia? Abra uma issue.
